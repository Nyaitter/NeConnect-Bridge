# クライアント

Windows で動くアプリです。つながりにくい場所からでも、いつものアプリを中継経由で使えるようにします。

## 画面の構成

上から順に、次のものが並びます。

1. ブリッジURLの一覧と「ブリッジURLをリクエスト」
2. Connect / Disconnect / 接続キャッシュをクリア
3. 起動対象: Chrome／Edge／NCTB Browser／任意のアプリケーション
4. Launch / ショートカットを作成 / ログ
5. 広告ブロック（入／切）
6. 状態の表示

## 使い方

1. 使うブリッジURLを上から順に並べます。
2. **Connect** を押すと中継につながります。このとき、まわりのアプリにも設定が反映されます。アプリは起動しません。
3. **Disconnect** を押すと切り、元の状態に戻します。

一度つながると、そのときの経路が `nctb_config.json` に残ります。次に Connect したときは、まずその経路でつなぎます。うまくいかないときは、これまでどおり先頭から順に試します。

**接続キャッシュをクリア** を押すと、残っている経路を消します。次は先頭から試します。

### 通常のブラウザで使う

Connect している間は、Windows のプロキシ設定がこのアプリを向きます。Launch を使わずに Chrome や Edge を普通に起動しても、そのまま中継経由になります。

### Launch

起動対象を選んで Launch を押すと、そのアプリを中継経由で開きます。

| 起動対象 | 内容 |
|---|---|
| Chrome | 入っている Chrome を専用の設定で開きます |
| Edge | 入っている Edge を専用の設定で開きます |
| NCTB Browser | 専用の軽量ブラウザを用意して開きます。初回は自動で取得します |
| 任意のアプリケーション | 指定したパスのアプリを開きます |

- すでに Connect しているときは、その接続をそのまま使います。アプリを閉じても接続は続きます。
- まだつながっていないときは、選んでいるブリッジURLでつないでから開きます。アプリを閉じると切断します。
- 任意のアプリケーションを選んだときだけ、パスの入力欄と「参照」が使えます。

### ドラッグ＆ドロップ

ウインドウへ `.exe` や `.lnk` をドロップすると、起動対象が「任意のアプリケーション」に切り替わり、そのパスが入ります。すぐには起動しません。Launch かショートカット作成を押してください。

### ショートカットを作成

Launch の横のボタンで、いま選んでいる起動対象のショートカットを作れます。保存先は Windows の保存ダイアログで選びます。初期の保存先はデスクトップです。

作られるショートカットはこのアプリ自身を指し、`--launch` で起動対象を指定します。アイコンは元のアプリのものです。ダブルクリックすると、つないでからそのアプリが開きます。

### ログ

「ログ」を押すと、動きの記録を別ウインドウで見られます。開いたままでも閉じても、接続には影響しません。

上へさかのぼって読んでいる間は、新しい記録が増えても表示は動きません。一番下まで戻すと、また新しい記録に合わせて進みます。Ctrl+A で全部を選べます。

ブラウザやアプリが自分から接続を切っただけのときは、記録に残りません。中継が止まったときなど、知らせるべきことだけが残ります。

### 広告ブロック

「広告ブロック」に印を入れると、広告と追跡の配信元への接続を、中継へ流す前に断ります。初期は切っています。入れたままにしたいときは、印を入れた状態が `nctb_config.json` に残り、次に開いたときも入ったままになります。

つないでいる途中でも、印の切り替えはすぐに効きます。断った回数はログにまとめて残ります。

ブリッジの接続先、`localhost`、私用の住所（`127.0.0.1` や `192.168.*` など）は止めません。

### 新しい版への入れ替え

つながると、新しい版が出ていないかを中継の上から確かめます。あれば同じ経路で取り寄せ、中身の照合値を確かめてから、このアプリのファイルを新しいものに入れ替えます。

入れ替えたあとに「今すぐ再起動して適用しますか？」と尋ねます。あとで、と答えたときは次に開いたときから新しい版で動きます。確かめられなかったときは記録に1行残すだけで、接続はそのまま続きます。

### 通知領域

ウインドウを最小化すると、タスクバーから消えて通知領域に移ります。アイコンを左クリックすると元の画面に戻ります。右クリックすると「開く」「終了」を選べます。つないだまま画面を片付けたいときに使えます。

このアプリが開いているときにもう一度起動すると、ウインドウは増えず、いま開いている画面が手前に戻ります。通知領域に移っているときは、そこから出てきます。

## ファイル

| 名前 | 内容 |
|---|---|
| `nctb_config.json` | 選んだ内容と、前回つながった経路です |
| `nctb.log` | 動きの記録です |
| `active_socks.json` | 接続中の入口の情報で、Connect 中だけ作られます |
| `runtime\` | 補助モジュールや内部で使うブラウザ・シェルです |

## ビルド

Go 1.26 以上を用意します。先に接続用の鍵とフック用モジュールを作ります。

```bash
# 接続用の鍵
ssh-keygen -t ed25519 -N "" -f client/id_ed25519_nctb

# フック用モジュール
zig cc -target x86_64-windows-gnu -shared -O2 -o client/nctb_hook64.dll hook/nctb_hook.c -lws2_32

# 本体
cd client
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -ldflags "-s -w -H windowsgui" -o NeConnectBridge.exe .
```

接続先と合言葉は `main.go` の先頭、サーバーの公開鍵は `internal/e2e/e2e.go` にあります。自分のサーバーに合わせて差し替えてください。
