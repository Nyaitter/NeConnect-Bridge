# クライアント

Windows で動くアプリです。つながりにくい場所からでも、いつものアプリを中継経由で使えるようにします。

## 画面の構成

上から順に、次のものが並びます。

1. ブリッジURLの一覧と「ブリッジURLをリクエスト」
2. 接続方法: オート／スピード／バランス／セキュア
3. Connect / Disconnect
4. 起動対象: Chrome／Edge／NCTB Browser／NCTB Bash／任意のアプリケーション
5. Launch / ショートカットを作成 / ログ
6. 状態の表示

## 使い方

1. 使うブリッジURLを上から順に並べ、接続方法を選びます。
2. **Connect** を押すと中継につながります。このとき、まわりのアプリにも設定が反映されます。アプリは起動しません。
3. **Disconnect** を押すと切り、元の状態に戻します。

### Launch

起動対象を選んで Launch を押すと、そのアプリを中継経由で開きます。

| 起動対象 | 内容 |
|---|---|
| Chrome | 入っている Chrome を専用の設定で開きます |
| Edge | 入っている Edge を専用の設定で開きます |
| NCTB Browser | 専用の軽量ブラウザを用意して開きます。初回は自動で取得します |
| NCTB Bash | 専用のシェルを別ウィンドウで開きます。初回は自動で取得します |
| 任意のアプリケーション | 指定したパスのアプリを開きます |

- すでに Connect しているときは、その接続をそのまま使います。アプリを閉じても接続は続きます。
- まだつながっていないときは、選んでいるブリッジURLと接続方法でつないでから開きます。アプリを閉じると切断します。
- 任意のアプリケーションを選んだときだけ、パスの入力欄と「参照」が使えます。

### ドラッグ＆ドロップ

ウインドウへ `.exe` や `.lnk` をドロップすると、起動対象が「任意のアプリケーション」に切り替わり、そのパスが入ります。すぐには起動しません。Launch かショートカット作成を押してください。

### ショートカットを作成

Launch の横のボタンで、いま選んでいる起動対象のショートカットを作れます。保存先は Windows の保存ダイアログで選びます。初期の保存先はデスクトップです。

作られるショートカットはこのアプリ自身を指し、`--launch` で起動対象を指定します。アイコンは元のアプリのものです。ダブルクリックすると、つないでからそのアプリが開きます。

### ログ

「ログ」を押すと、動きの記録を別ウインドウで見られます。開いたままでも閉じても、接続には影響しません。

## 接続方法

| 名前 | 内容 |
|---|---|
| オート | 速い順に試します |
| スピード | 速度を優先します |
| バランス | 安定性と速度を両立します |
| セキュア | 通りにくい回線向けの経路を使います |

## ファイル

| 名前 | 内容 |
|---|---|
| `nctb_config.json` | 選んだ内容です |
| `nctb.log` | 動きの記録です |
| `active_socks.json` | 接続中の入口の情報で、Connect 中だけ作られます |
| `runtime\` | 補助モジュールや内部で使うブラウザ・シェルです |

## ビルド

Go 1.26 以上を用意します。先に接続用の鍵とフック用モジュールを作ります。

```bash
# 接続用の鍵
ssh-keygen -t ed25519 -N "" -f client/id_ed25519_nctb

# フック用モジュール
zig cc -target x86_64-windows-gnu -shared -O2 -o client/nctb_hook64.dll hook/nctb_hook.c -lws2_32

# 本体
cd client
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -ldflags "-s -w -H windowsgui" -o NeConnectBridge.exe .
```

接続先は `main.go` の先頭にあります。自分のサーバーに合わせて差し替えてください。
