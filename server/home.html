NeConnect Bridge

いつものブラウザを、つながりにくい場所からでも使えるようにする小さな中継ツールです。

NeConnectBridge.exe をダウンロード

オート

速い順に接続を試します。

スピード

速度を優先して接続します。

バランス

安定性と速度を両立します。

セキュア

つながりにくい環境向けに接続します。

起動できるもの

Chrome

入っている Chrome を専用の設定で開きます。

Edge

入っている Edge を専用の設定で開きます。

NCTB Browser

専用の軽量ブラウザを自動で用意して開きます。

NCTB Bash

専用のシェルを別ウィンドウで開きます。

任意のアプリケーション

指定したアプリを中継経由で起動します。

Connect はつなぐだけ、Launch はアプリを開くだけ。役割は分かれています。

ブリッジURL

使い方

  1. NeConnectBridge.exe をダウンロードして起動します。
  2. 使うブリッジURLを上から順に並べ、接続方法を選んで Connect を押します。
  3. 起動対象を選んで Launch を押すと、中継経由でアプリが開きます。
  4. よく使うアプリは「ショートカットを作成」から好きな場所に保存できます。
  5. アプリをウインドウへドラッグすると、そのアプリが起動対象に入ります。
  6. 困ったときは「ログ」を押すと動きの記録を確認できます。

協力する

自分の Linux 環境で中継を起動し、公開URLを登録すると、ほかの人がそのURLを使えるようになります。
